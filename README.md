# Учебная практика 3.26

CRM-интерфейс для управления партнерами: многооконная навигация, форма добавления/редактирования, интеграция с БД (CRUD) и обработка исключений с интерактивными уведомлениями.

## Структура проекта

- `1) Проектирование многооконной архитектуры и навигации/` — переключение между `MainWindow` (реестр партнеров) и `PartnerEditWindow` (карточка партнера) без перезагрузки страницы и потери состояния; уникальные заголовки окон.
- `2) Разработка формы добавления и редактирования партнера/` — полная форма карточки партнера (наименование, тип, рейтинг, адрес, ФИО директора, телефон, email) с подсказками по формату ввода.
- `3) Интеграция формы с БД (CRUD-операции и обновление UI)/` — серверная часть на `node:sqlite`, REST API (`GET/POST/PUT /api/partners`), режимы добавления и редактирования с автоматической подгрузкой данных и обновлением списка.
- `4) Обработка исключений и интерактивные уведомления (UX и UI)/` — валидация полей на клиенте и сервере, `try/catch` вокруг операций с БД, диалоговые окна трех типов (ошибка / предупреждение / информация) с заголовками и пиктограммами.

## Запуск

Каждый этап — отдельный подпроект. Пример запуска:

```bash
cd "4) Обработка исключений и интерактивные уведомления (UX и UI)"
npm start
```

Приложение будет доступно на `http://localhost:3000`.
